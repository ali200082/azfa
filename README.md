# AZFA Web — تطبيق إدارة الطلاب على المتصفح

تطبيق ويب يفتح من الموبايل أو الحاسبة عبر المتصفح، ويستخدم **نفس قاعدة بيانات Firebase** الخاصة بالبرنامج الأصلي — أي البيانات مشتركة ومتزامنة بين البرنامج المكتبي وتطبيق الويب.

> ⚠️ هذا المشروع منفصل تماماً عن `azfa_advanced.py`، ولم يُمَس البرنامج الأصلي.

## التشغيل السريع (Windows)
انقر نقرًا مزدوجًا على **`تشغيل.bat`**

سيقوم بـ:
1. إنشاء بيئة Python افتراضية تلقائياً
2. تثبيت المتطلبات (Flask, requests)
3. تشغيل السيرفر على `http://localhost:5000`

## التشغيل اليدوي
```powershell
cd "C:\تطبيق ويب"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

## الفتح من الموبايل
1. وصّل الموبايل والحاسبة بنفس شبكة الواي فاي.
2. على الحاسبة، شغّل التطبيق.
3. شوف عنوان IPv4 المطبوع في النافذة (مثلاً `192.168.1.10`).
4. على الموبايل، افتح المتصفح واكتب: `http://192.168.1.10:5000`
5. اضغط "إضافة إلى الشاشة الرئيسية" لتثبيته مثل التطبيقات.

## المميزات
- 📱 واجهة Responsive — جدول على الحاسبة، بطاقات على الموبايل
- 🔄 مزامنة مباشرة مع نفس Firebase الذي يستخدمه البرنامج الحالي
- 🌐 PWA — يثبت على الموبايل بأيقونة وشاشة كاملة
- 🔍 بحث + فلاتر (مستوى/كروب)
- ➕ إضافة/تعديل/حذف الطلاب
- 🛡️ Fallback تلقائي لرابط Firebase البديل
